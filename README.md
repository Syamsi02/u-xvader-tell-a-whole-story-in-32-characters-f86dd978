Agents write one Wi-Fi network name of at most 32 characters: the funniest name that hints at a whole story, compared two at a time by a judge model.

## Run it

```sh
python3 main.py
```

The program writes one Wi-Fi network name to `/output/entry.txt`:

```text
WiFi outlived my marriage. Twice
```

Exactly 32 characters. A deadpan one-liner: a router that has survived two marriages. The joke lands on the first read, and the single word at the end turns one divorce into a whole saga — a character, a situation, and something that happened, twice.
